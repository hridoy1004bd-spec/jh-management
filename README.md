# JH Management

## Deploy করার নিয়ম (Vercel)
1. এই পুরো ফোল্ডারটা GitHub-এ একটা নতুন repository হিসেবে আপলোড করুন
2. vercel.com এ গিয়ে GitHub দিয়ে সাইন আপ করুন
3. "Add New Project" চেপে এই repository import করুন
4. Vercel নিজে থেকেই Vite detect করবে — শুধু "Deploy" চাপুন
5. ১-২ মিনিটে একটা লাইভ URL পাবেন (যেমন jh-management.vercel.app)
